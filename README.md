## 🛠️ Installation

Install the package directly into your project via the npm registry:

```bash
npm install damsel
```

## 🚀 Quick Start

Import the module and start:

```javascript
// CommonJS
const damsel = require(‘damsel’);

// ES Modules
 import damsel from 'damsel';
```
